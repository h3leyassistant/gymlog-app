# GymLog Ember — HTML mock

ตัว mock ใช้งานได้แล้ว: ธีมดำ–ส้ม ภาพ anatomy หน้า–หลังที่แตะเลือกได้ ค้นหาชื่อท่า บันทึกเซต และดูสรุป

## เปิดใช้งาน

จากโฟลเดอร์ `mock/ember` รัน:

```powershell
python -m http.server 8765 --bind 0.0.0.0
```

เปิด http://127.0.0.1:8765 บนคอม ใช้ URL/พอร์ตเดิมทุกครั้งเพื่อเข้าถึงบันทึกเดิม

บนมือถือที่ใช้ Wi-Fi เดียวกัน เปิด `http://<IP ของคอม>:8765` หากเครือข่ายและ firewall อนุญาต คอมต้องเปิด server ค้างไว้ ไม่ต้องติดตั้ง npm หรือ build แอพ ฟอนต์ ภาพ และสคริปต์อยู่ในโฟลเดอร์ทั้งหมด

ใน session ที่สร้าง mock ได้เปิด server พอร์ต 8765 ไว้แล้ว หากปิดโปรเซสหรือรีสตาร์ตเครื่อง ให้ใช้คำสั่งด้านบน

## ทดลอง

1. เปิดครั้งแรกเป็น **บันทึกส่วนตัว** ที่ว่างอยู่ กด "ดูข้อมูลตัวอย่าง" เพื่อลองกับข้อมูลตัวอย่าง (แก้ได้แต่ไม่บันทึก และจะเตือนตั้งแต่ครั้งแรกที่แก้)
2. แตะกล้ามเนื้อหรือใช้ปุ่มชื่อกล้ามเนื้อ สลับด้านหน้า/ด้านหลังได้
3. กดช่องค้นหาด้านบน หรือปุ่มเพิ่มท่า เพื่อเปิดรายการท่า มีท่าที่เคยเล่นล่าสุดให้กดเพิ่มทันที ค้นไทย/อังกฤษ/ชื่อย่อ (เช่น OHP) ได้ทีละคำ และกรองดัมเบล/เครื่อง แตะกล้ามเนื้อจะเห็นท่าที่ใช้กล้ามเนื้อนั้นเป็นส่วนเสริมด้วย
4. แตะรายละเอียดเพื่อดูแผนภาพช่วยจำ กด + เพื่อเพิ่มท่า
5. กรอกน้ำหนัก/จำนวนครั้ง แล้วยืนยันเซตที่ทำแล้ว (กด Enter เพื่อไปช่องถัดไปและยืนยัน) กด "ใช้ค่าครั้งก่อน" เพื่อเติมค่าเดิมแล้วยืนยันทีละเซต การแก้ตัวเลขจะยกเลิกการยืนยันเซตนั้น ลบเซตหรือท่าแล้วกด "เลิกทำ" ได้ บนมือถือภาพร่างกายจะย่อเองเมื่อวันนั้นมีท่าแล้ว
6. จากโหมดตัวอย่าง กด **เริ่มบันทึกของฉัน** เพื่อกลับมาจดจริง ข้อมูลตัวอย่างจะไม่ถูกคัดลอกมา
7. เปลี่ยนวันที่เพื่อจดย้อนหลัง เมนูสรุปแสดงเฉพาะเซตที่ยืนยันแล้ว: ภาพร่างกายระบายสีตามจำนวนเซต, ปฏิทินการฝึก (แตะวันเพื่อเปิดบันทึก) และกราฟน้ำหนักสูงสุดต่อวันของแต่ละท่า
8. เมนูข้อมูลรองรับส่งออกและนำเข้า JSON มีการยืนยันก่อนแทนที่บันทึกส่วนตัว ท่าที่เวอร์ชันนี้ไม่รู้จักจะถูกข้ามพร้อมแจ้งจำนวน (ตอนเปิดแอพจะเก็บสำเนาเดิมไว้ใน localStorage คีย์ `gymlog-ember-v1-backup-<วันที่>`) ถ้าอ่านบันทึกเดิมไม่ได้ ปุ่มส่งออกจะให้ข้อมูลดิบตามที่เก็บไว้

## ขอบเขต

- ภาพ anatomy สร้างด้วย AI เพื่อสื่อแนวคิด ไม่ใช่โมเดล 3D หมุนได้หรือแหล่งอ้างอิงทางการแพทย์
- กล้ามเนื้อ 18 กลุ่ม ตามการแบ่งของ free-exercise-db: คอ ไหล่ บ่า อก หลังส่วนบน ปีก หลังล่าง แขนหน้า แขนหลัง ปลายแขน หน้าท้อง ท้องด้านข้าง ต้นขาหน้า ต้นขาหลัง ก้น ต้นขาด้านใน สะโพกด้านนอก น่อง
- ส่วนที่กางเกงบัง (ต้นขาหน้า/หลังช่วงบน ต้นขาด้านใน สะโพกด้านนอก และก้น) เป็นขอบเขตประมาณจากโครงร่างขาและรอยพับ ไม่ได้ตามร่องกล้ามเนื้อจริง บนผ้าจะไฮไลต์เป็นสีส้มโปร่งแทนการย้อมสี
- คลังเริ่มต้น 35 ท่า สำหรับดัมเบลและเครื่อง 33 ท่ามีรูปท่าเริ่ม/ท่าจบจาก free-exercise-db อีก 2 ท่าใช้แผนภาพ รูปใช้ช่วยจำท่า ไม่ใช่คำแนะนำฟอร์ม และต้องตรวจสิทธิ์รูปก่อนใช้เชิงพาณิชย์ (ดู ATTRIBUTION.md)
- บันทึกเก็บใน localStorage ของเบราว์เซอร์นั้น ไม่มีบัญชีหรือการซิงก์มือถือ–คอม ใช้ export/import แทนได้
- ข้อมูลทดลองรีเซ็ตเมื่อโหลดหน้าใหม่ แต่บันทึกส่วนตัวอยู่ต่อ การล้างข้อมูลเบราว์เซอร์จะลบบันทึกได้
- เฟสนี้เน้นจดและสรุป ยังไม่ทำระบบจัดโปรแกรม เทรนเนอร์ หรือชำระเงิน
- แบบเดิมและข้อมูล brainstorm เก็บอยู่ในโฟลเดอร์ `mock` ชั้นบน

## สร้างภาพตัดพื้นหลังและพื้นที่กล้ามเนื้อใหม่

`assets/anatomy-cutout.webp` (ภาพตัดพื้นหลังแล้ว) และ `js/anatomy-regions.js` (เส้นขอบกล้ามเนื้อ) สร้างจาก `assets/anatomy-atlas.png` ด้วยสคริปต์ ห้ามแก้ด้วยมือ สคริปต์แบ่งพื้นที่แค่ครึ่งซ้ายของภาพ แล้วสะท้อนไปฝั่งขวา กล้ามเนื้อซ้ายขวาจึงเท่ากันเสมอ ถ้าจะปรับขอบให้แก้จุดตั้งต้นฝั่งซ้าย (`SEEDS` / `NEUTRAL`) ในสคริปต์ แล้วรันใหม่:

```powershell
pip install numpy opencv-python-headless scikit-image scipy
python tools/segment_anatomy.py
```

ใส่โฟลเดอร์ต่อท้ายคำสั่ง เช่น `python tools/segment_anatomy.py debug` เพื่อบันทึกภาพระบายสีแต่ละกลุ่มไว้ตรวจ
